DEVELOPER / PYTHON

Python Integration

Connect your Python application to Asyncate. 

import requests

API_URL = "https://YOUR-DOMAIN/api/v1/obfuscate"
API_KEY = "YOUR_API_KEY"

headers = {
    "Authorization": f"Bearer {API_KEY}"
}

with open("main.lua", "rb") as file:
    response = requests.post(
        API_URL,
        headers=headers,
        files={"file": file},
        timeout=60
    )

response.raise_for_status()

print(response.json())

Installation

Install the requests package using pip.

pip install requests
